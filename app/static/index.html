If you add your own API key, a short excerpt of the top problems (up to 5 groups, each sample cut to about 1,200 characters, never the whole log) is sent to the provider you choose, and that provider processes it under its own terms. This site does not save your key. Do not use this for logs you are not allowed to share with that provider.

How do I get an API key?
  1. Pick a provider below and open its keys page. You need an account there.
  2. Create a new key, give it any name, and copy it. Most providers show the full key only once, so copy it right away.
  3. Paste it into the key box here and press Load my models.
  • Groq keys page: has a free tier, so it is the easiest way to try this.
  • OpenAI keys page: usually needs prepaid credit on the account.
  • Anthropic keys page: usually needs prepaid credit on the account.

Keys that are shown to anyone else can be used on your account, so never post one publicly. If you pasted a key somewhere by mistake, delete it on the provider's page and make a new one.

The model list comes from the provider and shows what your key can use. Skip it to use the default.

What this tool does and does not do

  • It groups repeated errors by pattern. It does not understand your code.
  • Python, Java, Node.js, Go and C/C++ crashes are read in detail. Other languages are grouped by their message lines. JSON-lines and CSV logs are read field by field.
  • Only the most recent 50,000 lines are analyzed. Files up to 5 MB, pasted text up to 1 MB. A ZIP can hold up to 20 log files (20 MB unpacked).
  • Your log is analyzed in memory and not saved. Avoid pasting secrets such as passwords or tokens.
